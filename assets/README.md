# Static assets

Рекомендуется сохранить логотип локально в репозитории:
- `assets/logo.png` или
- `assets/logo.svg`

Текущая версия использует Drive URL:
`https://drive.google.com/uc?export=view&id=18dxhcc_PQ4YQaCDSY9Kgrv7hdsqCL2Kx`

Если публичный доступ к Drive-файлу ограничен, используется CSS fallback-эмблема `P`.
