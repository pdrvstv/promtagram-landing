# SOP — порядок экранов: Публикации → Доказательства

Дата: 17.09.2026
Статус: READY
Контур: 12_SOP / сайт Promtagram

## Назначение
Сохранить единственное изменение после отката homepage v10: экран `ПУБЛИКАЦИИ` должен непосредственно предшествовать экрану `ДОКАЗАТЕЛЬСТВА`.

## Реализация
Подключён `assets/publications-order-only.js`. Скрипт не меняет тексты, дизайн, контакты, меню или состав экранов. Он сохраняет исходный pre-v10 кластер `Признание → Партнёрство → Фотобанк → Система господдержки`, после чего размещает `Доказательства` сразу после `Публикаций` и запускает существующую функцию перенумерации v9.

## Rollback
Удалить подключение `publications-order-only.js` из `index.html` и сам файл. После этого порядок полностью вернётся к pre-v10.
