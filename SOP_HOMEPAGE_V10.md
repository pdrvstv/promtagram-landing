# Главная v10 — партнёрство, навигация, основатель

Дата: 17.09.2026
Статус: READY к публикации после проверки PR.
Контур: 12_SOP / сайт Promtagram.

## Назначение
Зафиксировать owner-approved изменение главной страницы без разрушительного редактирования базового шаблона v9.

## Изменения
1. Введена стабильная нумерация 01–19 по фактическому порядку смысловых экранов.
2. `06 / ОСНОВАТЕЛЬ PROMTAGRAM`: под фото добавлены рабочая почта `info@promtagram.ru`, личная почта `burnsmoneys@gmail.com`, телефон `+7 999 646-76-67`; левая колонка фото+контакты растягивается до высоты правого текстового блока.
3. `12 / ПАРТНЁРСТВО` расположен непосредственно перед `13 / ФОТОБАНК / АРХИВ` и состоит из двух половин:
   - ЦТИ «Нейролаб»: публичная карточка Promtagram на карте игроков ИИ-рынка России;
   - «ТехноБрокер»: визуализация входящего письма/аналитического профиля Promtagram AI/GR Project Office.
4. Формулировка по «ТехноБрокеру» намеренно не заявляет сертификат, госреестр, публичную аккредитацию или опубликованный кейсбук. Публично выводится только подтверждённый смысл письма.
5. `15 / ПУБЛИКАЦИИ` теперь непосредственно предшествует `16 / ДОКАЗАТЕЛЬСТВА`.
6. Второй экран `#site-map` содержит все 19 экранов главной страницы.
7. Верхнее меню содержит прямые ссылки на навигацию, основные коммерческие разделы, основателя, партнёрство, фотобанк, публикации и доказательства.

## Техническая реализация
Изменения реализованы обратимым слоем `assets/home-owner-v10.js` + `assets/home-owner-v10.css`, подключённым последним в `index.html`. Базовые файлы v9 не переписываются.

## Риски
- На странице присутствуют старые runtime-скрипты, которые также меняют порядок и номера секций. v10 выполняется последним, переопределяет `window.ptgRenumberScreens` и повторно применяет owner-order после `load`, включая финальную стабилизацию после отключения старых MutationObserver.
- Ссылка Нейролаба должна периодически проверяться на сохранение параметров карточки.
- Полный текст входящего письма «ТехноБрокера» публично не выводится.

## Проверка
Критические инварианты:
- `06 / ОСНОВАТЕЛЬ PROMTAGRAM`;
- `12 / ПАРТНЁРСТВО` непосредственно перед `13 / ФОТОБАНК / АРХИВ`;
- `15 / ПУБЛИКАЦИИ` непосредственно перед `16 / ДОКАЗАТЕЛЬСТВА`;
- второй экран содержит 19 ссылок;
- email/tel ссылки кликабельны.

## Rollback
Revert merge-коммита v10 либо удалить два подключения `home-owner-v10.*` из `index.html`. Базовая v9 после этого остаётся неизменной.
