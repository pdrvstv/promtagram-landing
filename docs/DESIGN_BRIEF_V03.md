# Promtagram Landing v0.3 — Lovable-based Visual Rebuild

## Цель

Пересобрать публичный статический лендинг в премиальную институциональную B2B/GovTech подачу с фокусом на конверсию в заявку.

## Визуальный ориентир

Основной референс:
https://promtagram.lovable.app/

Берём:

- общую сценографию;
- ритм иерархии;
- премиальную плотность первого экрана;
- продуктовую подачу блоков;
- аккуратные CTA и статусные маркеры.

## Сценарий страницы

1. Header
2. Hero + ИИ-скан поддержки
3. Institutional trust contour
4. Product value proposition
5. Route/support map
6. Industry scenarios
7. Process + result
8. Evidence / trust discipline
9. Work formats
10. Lead form section
11. Footer

## Язык и комплаенс

- Русский как основной интерфейс.
- Без обещаний одобрения и без “гарантий результата”.
- Допустимый фрейминг:
  - предварительная оценка;
  - скоринг применимости;
  - карта возможных мер;
  - маршрут документов;
  - проверка рисков;
  - решение принимает оператор программы.

## Интеграции

- Google Form public URL: неизменен.
- Google Form embed URL: неизменен.
- CRM контур: без изменений.

## Ограничения реализации

- Только статический фронтенд:
  - `index.html`
  - `styles.css`
  - `script.js`
- Без Apps Script, backend, React, библиотек, CDN, трекеров и аналитики.
- Без официальной государственной символики и защищённых сторонних логотипов.
