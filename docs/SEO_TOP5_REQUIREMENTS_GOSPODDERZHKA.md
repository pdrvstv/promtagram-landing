## Query

Primary head query:

- `господдержка`

Business-intent variants:

- `господдержка бизнеса`
- `поддержка бизнеса`
- `меры господдержки для бизнеса`
- `субсидии для бизнеса`
- `ФРП для производства`
- `субсидии на оборудование`
- `господдержка автоматизации производства`

## Strategic conclusion

Promtagram should not attempt to win the generic `господдержка` query directly in the first stage.

The generic query is broad and mixed-intent. It can mean support for citizens, mortgages, business, agriculture, industry, regions, military, families, social benefits, transport, exporters, and other topics.

For Promtagram, the correct strategic target is:

1. Own business-intent long-tail and middle-tail queries first.
2. Build topical authority around government support routes for business.
3. Use cases, evidence, document routes, and risk checks as differentiators.
4. Only then compete for broad head terms.

## SERP reality

The current visible search landscape for `господдержка` and related terms is dominated by:

- official platforms;
- regional `Мой бизнес` centers;
- state support aggregators;
- banks;
- legal and financial information portals;
- large media and business publications;
- active news pages.

Promtagram is a new domain and cannot yet compete with these on authority alone.

### Engagement requirements

Track through Search Console / Webmaster and optionally analytics:

- CTR by query.
- Indexed pages.

- Average position.

### Differentiator requirements

Promtagram must not look like another generic support article.

Each strong page should have:

- route map;

- preliminary scoring logic;
- case/reconstruction block;
- CTA to scoring;
- disclaimer that approval is not guaranteed.
