# RF compliance readiness checklist — promtagram.ru

Дата: 21.08.2026  
Статус: HOLD

Этот checklist используется как финальный gate перед переводом legal-ветки и production-сайта в READY.

## A. Оператор

- [ ] Подтверждено точное наименование / ФИО оператора персональных данных.
- [ ] Подтверждены ИНН и ОГРН / ОГРНИП, если применимо.
- [ ] Подтверждён адрес / место нахождения.
- [ ] Утверждён e-mail для обращений субъектов ПД.
- [ ] Подтверждено, что именно этот оператор отвечает за `promtagram.ru` и обработку заявок.

## B. Роскомнадзор и локальные документы

- [ ] Проверено уведомление / запись оператора в реестре Роскомнадзора.
- [ ] Цели, категории субъектов и данных соответствуют фактическому сайту и CRM.
- [ ] Указано фактическое место нахождения базы данных.
- [ ] При необходимости обновлено уведомление об обработке ПД.
- [ ] Проверена необходимость уведомления о трансграничной передаче и выполнены требования, если применимо.
- [ ] Утверждены внутренние политика, роли доступа, сроки хранения, уничтожение и incident-response.

## C. Intake и локализация

- [ ] Первичная запись интернет-заявки граждан РФ происходит в подтверждённую базу на территории РФ.
- [ ] Зафиксирован маршрут `website → RU raw intake → validation → clean CRM`.
- [ ] Google Forms не используется как неподтверждённый primary intake.
- [ ] Роль Google Workspace / иных иностранных сервисов описана как допустимая последующая обработка, если они используются.
- [ ] Настроен минимальный состав собираемых данных; специальные категории и избыточные данные не запрашиваются.

## D. Consent

- [ ] Checkbox на обработку ПД не предустановлен в **статическом HTML**.
- [ ] Checkbox обязателен для отправки основной заявки.
- [ ] Рядом доступны ссылки на `consent.html` и `privacy.html`.
- [ ] Согласие оформлено отдельно от иных документов/подтверждений.
- [ ] Intake сохраняет `consent_version`, дату/время, источник, ID заявки и факт активного opt-in.
- [ ] Отзыв согласия маршрутизируется на подтверждённый контакт оператора.
- [ ] Рекламное согласие отделено от согласия на обработку входящей заявки.
- [ ] Отказ от рекламного opt-in не препятствует основной заявке.

## E. Политика

- [ ] В `privacy.html` нет BLOCKED-полей.
- [ ] Категории данных совпадают с реальными полями формы/CRM.
- [ ] Цели обработки соответствуют фактической работе.
- [ ] Описаны реальные обработчики / получатели.
- [ ] Описана локализация и, если применимо, трансграничная передача.
- [ ] Зафиксированы реальные сроки хранения и уничтожения.
- [ ] Меры защиты описаны без неподтверждённых технических обещаний.

## F. Advertising

- [ ] Если рекламные коммуникации используются, включён отдельный добровольный opt-in.
- [ ] Фиксируются канал, версия согласия, дата/время и доказательство opt-in.
- [ ] Реализован отказ / unsubscribe / stop по соответствующему каналу.
- [ ] Определён рекламораспространитель и контакт для отказа.

## G. Evidence / marketing claims

- [ ] `980+ маршрутов` подтверждено Evidence Log или удалено.
- [ ] `520+ мер` подтверждено Evidence Log или удалено.
- [ ] `85 регионов` подтверждено фактическим покрытием или переформулировано.
- [ ] `92% качество документов` подтверждено методикой и выборкой или удалено.
- [ ] `500+ проектов` подтверждено реестром или удалено.
- [ ] `40+ млрд ₽` подтверждено первичными данными и методикой или удалено.
- [ ] `20+% повторных запросов` подтверждено CRM-выгрузкой или удалено.
- [ ] `95% экспертных заключений` подтверждено методикой или удалено.
- [ ] «Собственный кейс» и `+23% / –17% / 8 мес.` имеют первичные документы и право публикации либо маркируются как демо/удаляются.
- [ ] SLA «следующий рабочий день» подтвержден операционным SLA либо смягчён.
- [ ] Demo score `78/100`, `82/100` явно маркирован как демонстрация.

## H. Technical QA

- [ ] `index.html` не содержит `checked` у consent checkbox.
- [ ] `index.html` содержит HTML-level `required` для consent checkbox.
- [ ] Legal links доступны без зависимости только от JavaScript.
- [ ] При отключённом JS форма не отправляет введённые ПД в query string текущей страницы.
- [ ] Нет нового tracking / analytics / external scripts без отдельного privacy review.
- [ ] Desktop/mobile визуальный QA пройден.
- [ ] Тестовая заявка выполнена синтетическими данными.
- [ ] Тестовая запись найдена на каждом ожидаемом этапе маршрута и затем удалена по тестовой процедуре.

## Release decision

READY допускается только если разделы A–H закрыты документально и фактический маршрут соответствует опубликованным текстам. Наличие красивой политики без совпадения с реальной архитектурой не считается соответствием.
