### Скоринг и проверка применимости

- карта мер поддержки

### Инструменты поддержки

- субсидии для бизнеса

- лизинг оборудования с поддержкой

### Документы и риски

- документы для господдержки
- инвестплан для субсидии
- проверка ОКВЭД для поддержки
- риски при подаче на господдержку

## Запрещённые SEO-формулировки

Не использовать:

- гарантированное получение субсидии;
- 100% одобрение;
- получим деньги от государства;
- одобрим займ;
- субсидия без риска;
- связи в министерствах;
- гарантированный результат.

## Разрешённые формулировки

Использовать:

- предварительная оценка;
- скоринг применимости;
- карта возможных мер;
- маршрут документов;
- проверка рисков;
- подготовка к подаче;
- решение принимает оператор программы.

## Следующий слой SEO

После индексации главной страницы:

1. Создать отдельные посадочные страницы:
   - `/frp/` — ФРП и займы для производства;
   - `/msp/` — меры поддержки МСП;
   - `/export/` — РЭЦ и экспортные маршруты;
   - `/leasing/` — лизинг и компенсации;
   - `/apk/` — АПК и переработка;
   - `/automation/` — роботизация и автоматизация.
2. Добавить `sitemap.xml` с новыми страницами.
3. Не создавать страницы без проверки Risk QA.
4. Не обещать получение поддержки.

## READY gate

Контентный SEO-слой считается применённым после:

- деплоя GitHub Pages;
- проверки FAQ на сайте;
- проверки structured data валидатором;
- отправки главной страницы в Google Search Console и Яндекс Вебмастер.
