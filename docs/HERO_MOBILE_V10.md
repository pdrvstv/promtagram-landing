# Первый экран Promtagram — mobile v10

Дата: 17.09.2026
Статус: HOLD до проверки production после merge.
Контур: 12_SOP / сайт Promtagram.

## Проблема
Первый экран на мобильных устройствах одновременно управлялся тремя CSS-слоями: `hero-static-cover-v6.css`, `hero-responsive-v8.css` и `hero-mobile-clean-v9.css`. Более поздние файлы переопределяли предыдущие правила. Дополнительно использовались большие искусственные `padding-top` 92–245 px и фон из полной desktop-обложки, из-за чего на коротких экранах hero становился выше viewport, появлялись обрезание, дубли desktop-текста и горизонтальное переполнение.

## Решение
1. Единственный активный источник стилей hero — `assets/hero-static-cover-v6.css`.
2. Подключения `hero-responsive-v8.css` и `hero-mobile-clean-v9.css` из `index.html` сняты; сами файлы оставлены в репозитории как история и rollback-материал.
3. На mobile первый экран фиксирован в `100svh` и ограничен `100vw`; внутренний контейнер также не может расширять viewport.
4. Удалены искусственные вертикальные отступы под изображение. Компоновка: верхняя панель → текст/CTA → нижняя метка.
5. CTA остаются в две колонки даже на 320 px, чтобы короткие экраны не разрастались по высоте.
6. Фоновая иллюстрация использует контролируемый crop правой части существующей approved-обложки, без отдельного нового актива и без попадания desktop-заголовка в mobile.
7. Для `max-height:650px` есть отдельная компактная геометрия.
8. Desktop/ultrawide-логика из responsive v8 перенесена в основной hero stylesheet, поэтому снятие двух дополнительных CSS не ухудшает desktop.
9. Cache key изменён на `hero-static-cover-v6.css?v=20260917-mobile-v10`.

## DRY_RUN / QA
Локально проверены viewport:
- 320×568;
- 375×667;
- 390×844;
- 430×932;
- 768×1024.

Во всех проверках:
- hero height = viewport height;
- document scrollWidth = viewport width;
- горизонтального overflow нет;
- desktop-текст не дублируется в декоративном mobile-фоне;
- обе CTA видимы в первом экране.

## Риск
Средний только для визуальной композиции первого экрана. Другие секции, формы, SEO, CNAME и data routing не изменяются.

## Rollback
Вернуть подключение `hero-responsive-v8.css` и `hero-mobile-clean-v9.css` в `index.html`, восстановить предыдущую версию `hero-static-cover-v6.css` и cache key.
