## DRY_RUN и изменения

Причина: CSS radial mask плюс увеличение 216% скрывали края; меню было внутри hero.
План: отдельное полное изображение, без mask/crop; единственный header непосредственным потомком body перед main, position:sticky; top:0; z-index:1000.
Header заменяет старый header в index.html через Liquid. Якорный отступ учитывает фактическую высоту меню через ResizeObserver; без JS остаются CSS-отступы. Мобильная панель переносит ссылки на вторую строку. Содержание остальных секций не изменяется.

Артефакты: _includes/site-header-native.html, _includes/hero-native.html, assets/hero-native.css, assets/site-header-native.js, assets/hero-full-illustration-v2.webp, index.html.
Изображение: 1254×1254, WebP quality 90 без resize, 150366 байт. Встроенный imagegen, редакция исходного hero-approved-reference-v7.webp. Мелкие детали могут отличаться от оригинала.
