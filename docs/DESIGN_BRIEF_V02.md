# Promtagram Landing v0.2 — Design Brief

## Цель

Премиальный институциональный B2B / GovTech лендинг для конверсии трафика в заявку на предварительный скоринг господдержки.

## Формат

Полностью статический фронтенд для GitHub Pages:

- `index.html`
- `styles.css`
- `script.js`

Без backend, Apps Script, фреймворков, CDN, аналитики и внешних библиотек.

## Позиционирование

Promtagram — операционная система предварительного скоринга господдержки для бизнеса.

## Воронка

Скоринг → карта мер → маршрут документов → проверка рисков → заявка.

## Дизайн-логика

- Scene-based структура вместо набора одинаковых карточек.
- Тёмный бренд-контур и премиальный hero.
- Dashboard-макет `ИИ-скан поддержки`.
- Маршруты поддержки и отраслевые сценарии.
- Операционная последовательность обработки заявки.
- Доказательный контур / evidence discipline.
- Интегрированная lead-секция с Google Form.

## Язык

Русский, строгий деловой тон, без гипербол и обещаний одобрения.

## Комплаенс

Запрещены формулировки:

- гарантируем получение господдержки;
- 100% одобрение;
- получим деньги от государства;
- решим через связи;
- гарантированный результат.

Разрешённая рамка:

- предварительная оценка;
- скоринг применимости;
- карта возможных мер;
- маршрут документов;
- проверка рисков;
- сопровождение без гарантии одобрения.

## Интеграция

Google Form public URL и embed URL сохранены без изменений.

## Статус

`PUBLISHED_UNTESTED_STATIC_V0_2` до подтверждения тестовой заявки в CRM.
